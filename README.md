# Star News 24/7

This repository contains the Django project for Star News 24/7.



## Project structure

- `manage.py` - Django management entry point
- `news/` - app containing models, views, serializers, and templates
- `starnews_project/` - Django project settings and URLs
- `templates/` - HTML templates for the site
- `static/` - CSS and JavaScript assets

## Notes

This project appears to manage YouTube news videos and user interactions such as likes and comments.
